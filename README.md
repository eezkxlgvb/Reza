# 🌊 Flow — صفحه ورود با افکت مایع و حباب

یک صفحه ورود زیبا و تعاملی با انیمیشن‌های حباب‌های شناور، افکت مایع و طراحی مدرن.

## ✨ ویژگی‌ها
- حباب‌های پس‌زمینه با حرکت و شناوری
- انیمیشن موج مانند روی دکمه ورود
- افکت تعقیب ماوس روی حباب‌ها
- طراحی شیشه‌ای (Glassmorphism)
- کاملاً ریسپانسیو

## 🚀 اجرا در Railway
1. این ریپازیتوری را به گیت‌هاب آپلود کن.
2. در Railway یک پروژه جدید ایجاد کن و به گیت‌هاب متصل کن.
3. Railway به‌طور خودکار پروژه را بیلد و اجرا می‌کند.
